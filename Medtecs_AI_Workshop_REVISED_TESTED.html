STEP 02LEARN2 min

You do not need a perfect prompt.

Start by saying what you need in normal language. AI can help you make the request clearer.

START SIMPLE
I'm organizing an AI workshop for our employees. I need to divide the participants into teams for a group project. I have their survey responses. Help me form useful teams.
Beginner lesson: Start with the task. You can add context when you need it.
Presenter cue

Ask: “What does AI still need to know?” Expected answers: survey data, what makes a useful team, preferred team size.

STEP 03WATCH5 min

Basic prompting: Task → Context → Output.

Now give AI the survey and the rules that actually matter. The project theme comes first; department and AI confidence are secondary balancing factors.

TESTED TEAM-GROUPING PROMPT
I need to form teams for our AI workshop group project.

TASK
Create useful teams from the participant survey I upload.

CONTEXT AND RULES
- The FIRST survey response was a test submitted by Ever. Exclude only that first test response from all counts and grouping.
- Target about 4 people per team. If the total does not divide evenly, teams of 3–5 are acceptable and team sizes should differ by no more than 1 when possible.
- PRIMARY goal: group people with similar or compatible work pain points so each team can choose one meaningful project.
- SECONDARY goal: where possible, mix departments and AI confidence levels within each team.
- Do not sacrifice a shared project theme just to maximize department diversity.
- Use only fields that actually exist in the survey. Do not invent missing information.

OUTPUT
First state the valid participant count after removing the test response. Then show a table with: Team, Participant ID/Name, Department, Work Pain Point, AI Confidence, Shared Project Theme, and a one-sentence reason for the grouping.

CHECK
After the table, audit your own grouping: list any omitted or duplicated participants, show each team size, and flag any team that needs human review. If a required survey field is missing, tell me before making assumptions.
Upload the cleaned/approved survey file, then run this prompt. Project only fields approved for the workshop.
Presenter cue

Say: “This is still normal language. I told AI the task, gave it context and said what I want back.”

STEP 04CHECK3 min

Looks organized. But is it correct?

Do a fast audit before announcing the teams. A second AI answer is not independent verification—compare the result with the cleaned survey.

Coverage

Every valid participant exactly once?

Size

Teams reasonably even?

Theme

Can each team see a shared project problem?

Human check

Any practical change needed?

OPTIONAL RECHECK
Recheck the proposed teams against the uploaded survey. Confirm the valid participant count, list any omitted or duplicated participant IDs/names, show each team size, and flag any grouping that does not have a clear shared work theme. Do not change the teams unless you explain why.

DEMO PROMPT
Compare the three FICTIONAL supplier quotations below for an order of 300,000 pieces.

Create one table with: Supplier, Unit Price, Currency, MOQ, Incoterm / delivery basis, Freight status, Lead Time, Payment Terms, Calculable Total, Comparable? (Yes/No), and Missing / Unclear Information.

Rules:
- Use only the information below. Do not invent assumptions.
- Do not convert currencies unless an exchange rate is provided.
- Calculate a total only when the arithmetic is supported by the quotation.
- Do not rank or choose a supplier.

STEP 09WATCH12 min

Don't just get an answer. Check where it came from.

Use a small set of approved sample documents. Ask a question that requires finding and combining information across the sources.

DEMO QUESTIONS
Using only the sources in this notebook, prepare a concise submission checklist for the fictional “2026 Sample Protective Equipment Purchase.”

Include:
- submission deadline and time;
- requested quantity;
- required submission documents;
- packaging and labeling requirements;
- delivery / lead-time requirement;
- deadline for questions.

For every item, identify the supporting source. Then answer these two checks:
1. Is a factory inspection date specified?
2. Which internal department is responsible for each submission item?

If the sources do not contain an answer, write exactly: “Not found in the provided sources.” Do not infer or invent it.
Download the three fictional source files below, add them to one Gemini Notebook, run the prompt, then open at least one citation live.
Takeaway: Use Gemini Notebook when the task depends on a defined set of reference materials and you want an easy path back to the source.
STEP 10WATCH10 min

Can one prompt reveal my repetitive work?

Antigravity is an agentic development platform. For this beginner demo, use it only with a small approved sample pack to identify a repeated workflow and produce a reviewable result—no live email actions.

ONE PROMPT · Copy into Antigravity
Review ONLY the approved work examples I paste below. Do not access other accounts, send messages, edit external records or take actions.

Goal: identify up to 3 repeated workflows that may be worth improving.

For each workflow, show:
- Trigger: what starts the task
- Repeated steps
- Input: information needed
- Output: what is produced
- Evidence: which example IDs support the pattern
- Possible AI/automation help
- Human check that should remain

Rules:
- Call something “repeated” only if at least 2 examples support it.
- Mark uncertain points as “Needs confirmation.”
- Do not invent missing steps.
- End with ONE small, low-risk workflow that would be easiest to demonstrate, and explain why.

APPROVED FICTIONAL EXAMPLES
E1 — Every Monday, an operations coordinator collects status updates from several colleagues and copies completed items, open items and blockers into a weekly report.
E2 — The following Monday, the coordinator again receives separate status updates and manually combines them into the same weekly report format.
E3 — A third weekly cycle shows the same pattern: collect updates, identify missing owners/dates, draft the report, then send it to a manager for review.
E4 — Purchasing receives Supplier A and Supplier B quotations and manually copies price, lead time and payment terms into a comparison table.
E5 — On another purchase request, Purchasing compares three quotations using the same fields and asks suppliers to clarify missing delivery terms.
E6 — After one meeting, an administrator converts notes into action items and sends them to attendees.
Paste the prepared examples into the ONE prompt. Ask the class which pattern appears most often; keep the results for the live workflow demo after the drink challenge.
Use fictional or company-approved examples. Antigravity can execute agentic development tasks, so keep this classroom demo scoped to the provided sample material unless IT has approved broader access.
